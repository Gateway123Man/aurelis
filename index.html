The idea

A launcher that gets out of the way.

Aurelis is being designed for players who want control without clutter. Separate profiles keep versions, mods, and settings from bleeding into each other. The interface stays quiet until you need it, and every action has a clear result.

One place for every profile

Each profile gets its own game directory, loader, Java runtime, memory, resolution, mods, and HUD layout. Duplicate a setup or start clean without touching the others.

Real tools, not buzzwords

Downloads are verified, repairs only replace broken managed files, and performance suggestions explain the trade-off. No invented FPS numbers and no silent “optimizations.”

Local-first by design

Profiles, worlds, logs, and playtime stay on your device. Account tokens live in the operating system credential vault. Telemetry is off by default — and the privacy policy says exactly what happens.

What is being built

Everything in one place. Nothing forced on you.

The launcher and the in-game client are separate components. You can use Aurelis purely as a launcher, or add the Fabric client for HUD modules and cosmetic features. Modules are individually configurable and can be disabled per server.

Client-side

Fair play

Useful on the HUD. Invisible to the fight.

Aurelis is built around information and customization, not combat automation. The client will not include cheats, and it will not try to evade server anti-cheat systems.

  • No combat automation. No kill aura, reach, aim assist, hitbox expansion, auto-clicker, or packet manipulation.
  • Only information the game already gives you. HUD modules display FPS, ping, coordinates, armor, potions, and similar client-side data.
  • Per-server control. Optional modules can be disabled for a server, and server-specific HUD layouts keep your setup appropriate for the community.
  • Honest cosmetics. Local capes and themes are client-only. If a cosmetic is not visible to other players, Aurelis says so.

The standard

“If it changes what the server sees or what your character can do in combat, it does not belong in Aurelis.”

Security and privacy

Your account stays yours.

Authentication happens in your browser through Microsoft’s device-code flow. Aurelis never asks for your Microsoft password, and it never stores one. The full policy is available in the privacy section.

No password handling

You sign in on Microsoft’s site. Aurelis receives tokens, not credentials, and never sees your MFA codes or recovery information.

OS-level token storage

Refresh tokens are kept in the platform credential vault. Access tokens stay in memory and are not written to logs or configuration files.

Verified downloads

Minecraft files, mods, and runtimes are checked against published hashes where available. ZIP extraction rejects path traversal and unexpected absolute paths.

Local by default

No telemetry, no analytics, no background account sync. Logs and crash reports stay on your device unless you explicitly export them.

Questions

The short answers.

If something is not covered here, the contact section below is the right place to ask. For API review questions, the privacy policy describes the intended data handling in detail.

Is there a download available?

Not yet. Aurelis is pre-alpha. This page will be updated when a signed public build is available. There are no unofficial downloads, and you should not trust a build claiming to be Aurelis from anywhere else.

Is Aurelis free?

Pricing has not been announced. If a paid edition is introduced, it will be stated clearly before release. The project will not hide costs behind a fake “free” download.

Is Aurelis affiliated with Mojang or Microsoft?

No. Aurelis is an independent project. It is not affiliated with, endorsed by, or associated with Mojang Studios, Microsoft, Fabric, Modrinth, or any other third party. Minecraft is a trademark of Mojang Synergies AB.

Does it support cracked or offline accounts?

No. Aurelis is designed for legitimate Microsoft accounts and respects Minecraft licensing. It does not bypass authentication or ownership checks.

Which Minecraft versions will the in-game client support?

The launcher is being designed to manage multiple Minecraft versions. The initial Fabric client target is Minecraft 26.3. Other versions can still be launched, but Aurelis modules require a compatible client build; the launcher will say so clearly.

Is the HUD a cheat?

No. Aurelis is fair-play only. The HUD displays information the game already provides, and the client does not include kill aura, reach, aim assist, packet manipulation, or anti-cheat bypasses. Optional modules can be disabled per server.

Where is my data stored?

Profiles, worlds, settings, logs, and playtime are stored locally on your device. Account refresh tokens are stored in your operating system’s credential vault. The app does not run a telemetry service. See the privacy policy.

Will it work on macOS or Linux?

Windows is the first target. The planned stack is cross-platform, but macOS and Linux support have not been announced. The website will state supported platforms before any release.

How can I follow development?

Use the GitHub repository linked in the contact section. This page is the official information hub; any future release notes and download links will be published here first.
